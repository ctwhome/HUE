## One active contract

HUE is an active native Bun/SvelteKit implementation for exactly three user-facing objects. Hermes owns agent execution and transcripts; HUE owns local organization and reliable delivery state.

<CardGrid>
  <Card title="Projects">
    Work inside Hermes-authoritative, trusted local folder boundaries with bounded files, terminals, Git, browser, and Excalidraw tools.
  </Card>
  <Card title="Workflows">
    Save reusable Project prompts and launch settings without introducing a generic workflow engine.
  </Card>
  <Card title="Sessions">
    Create or resume Project and projectless Hermes conversations with complete-envelope submission, idempotency, serialization, and replay.
  </Card>
  <Card title="Decisions">
    **[Review every accepted architecture decision →](./spec/14-decision-register/)**
  </Card>
</CardGrid>

## Current supporting surfaces

Focused ADRs retain notifications, Hermes-owned schedules with dedicated projectless Sessions, Project Excalidraw, and a hardened custom-skill filesystem exception. They remain supporting surfaces and do not expand the product object model.
