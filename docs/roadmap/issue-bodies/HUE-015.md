## Goal

Make maintained knowledge, memory layers and exact retrieval inspectable and correctable.

## Scope

- Show context-pack roles and version history
- Show backlinks/tags/provenance and epistemic type
- Show global/Space/source/episodic layers
- Preview proposed edits and context manifests

## Acceptance criteria

- [ ] User can answer why a source was loaded
- [ ] User can edit/supersede/delete appropriate records
- [ ] Raw transcript is not mislabeled as durable knowledge
- [ ] Source freshness and authority are visible
- [ ] Sensitive values remain redacted
