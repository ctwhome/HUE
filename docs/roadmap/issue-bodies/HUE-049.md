## Goal

Turn completed work into concise resumable Session summaries and reviewable updates to current state/decisions/active work.

## Scope

- Generate structured Session close summary
- Propose context-pack/knowledge changes as diffs
- Link evidence, source records and superseded state
- Accept/reject/edit proposal with provenance

## Acceptance criteria

- [ ] Summary captures goal/outcome/blockers/evidence/open threads
- [ ] No durable Space update occurs without policy/user acceptance
- [ ] Accepted change updates canonical file/record and indexes
- [ ] Rejected proposal remains audit-visible but unretrieved
- [ ] Old current state is superseded rather than silently overwritten

## Non-goals

- Copy full transcript into context pack

## Implementation handoff requirements

- Preserve the documented security, project, memory and event boundaries.
- Add or update automated tests for every observable acceptance criterion.
- Provide real verification output; do not rely on a worker/agent self-report.
- Update only the exact documentation sections whose status changed.
- Include screenshots or a recording for user-interface changes.
- Include migration, rollback and recovery notes for data/state changes.
- Link the pull request to this issue with `Closes #<issue-number>`.
