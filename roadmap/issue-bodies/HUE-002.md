## Goal

Decide HUE’s owned personal-workspace boundary and the replaceable relationship to Hermes/OpenCode plus the application shell and control plane.

## Scope

- Spike Tauri, browser+daemon and existing Hermes WebUI extension paths
- Compare TypeScript, Rust, Python/Hermes-derived and split daemon options
- Document HUE ownership of Spaces, Sessions, context packs and task state
- Document reuse/adapter boundaries for Hermes and OpenCode

## Acceptance criteria

- [ ] ADR covers TBD-001, TBD-002 and TBD-004
- [ ] At least one runnable thin spike per finalist
- [ ] No backend-native session/memory is made canonical accidentally
- [ ] Decision scores recovery, packaging, reuse, accessibility and contributor ergonomics
- [ ] Consequences and migration path are explicit
