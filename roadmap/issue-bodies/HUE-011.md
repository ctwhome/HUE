## Goal

Expose coherent Space navigation while preserving meaningful Project versus Area behavior.

## Scope

- Build shared Overview/Sessions/Tasks/Knowledge/Files/Decisions/Activity/Settings tabs
- Build repository/folder import for Projects
- Build template-based Area onboarding without repository assumptions
- Show context-pack/source/permission health
- Implement empty, degraded and archived states

## Acceptance criteria

- [ ] Notidian-like Project shows repository/source state
- [ ] Health-like Area shows goals/current system/observations/questions
- [ ] Space tabs and terminology are consistent
- [ ] Area UI never invents branches/worktrees unless linked
- [ ] Accessibility and responsive states pass
